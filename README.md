# Christmas-never-gets-old

I like to repair Christmas decorations, but this specific decor gave me a lot of problems. The problem at first was that sometimes it would turn on, sometimes it would only light up, sometimes it would only sing, or sometimes the motor would only turn on. I opened it up, and everything looked good, the conenctions seemed fine so i kept checking things till i doun a transistor that seemd to not work fine so i took it out but when doing so i messed up the pcb by taking off the little petal circles where the components go at (this often happens to me i think is because of my soldering iron). So after this, I left it there, not doing anything, and only checked and tried to fix it once in a while. At the end because i left it open some cables got loose and i couldnt find where they went and since it is an older generic model there was no resources online (i couldnt even find a picture or video similar to it) so this project will no concist instead of trying to fix it to redo the whole thing. I will use an Arduino and separate components to replace the old ones (I will only keep the old motors and LEDs). I'll try to keep the same function as before, as well as the song, though I may add other songs if I can get this to work. If possible, I will reuse the same base of the Santa.
